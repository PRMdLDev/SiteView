Sobre o SiteView

SiteView 2.0 é um visualizador local para projetos web. O projeto é carregado e processado no navegador, sem envio automático dos arquivos para um servidor.

  • Suporte a pastas, arquivos individuais e ZIP.
  • Detecção de index.html e seleção de outra página quando necessário.
  • Preparação de caminhos locais para HTML, CSS, JS e recursos.
  • Visualização em tela cheia e controles adaptados a telas pequenas.
  • Diagnóstico básico de erros de JavaScript durante a execução.

Importante: projetos que dependem de PHP, Node.js, APIs próprias, banco de dados, servidor web ou serviços externos não podem ser transformados em backend apenas pelo navegador. Eles precisam do ambiente correspondente.

Instalação: quando o navegador permitir, use o botão Instalar no topo para adicionar o SiteView como aplicativo. Em celulares, o navegador pode oferecer a opção “Adicionar à tela inicial”.
